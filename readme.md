# B-IM-120W-24V

电机 + 驱动一体的小型电机一体机：出厂即集成驱动与电机，客户免驱直用，面向小功率场景的即插即用需求。当前为规划中的骨架文档，功能与参数以定型为准，未定型处标注 TBD。

- 产品线：方案开发板（B）
- 产品编码：B-IM-120W-24V（B=方案开发板线，IM=电机一体机，120W=功率档，24V=供电电压规格码）
